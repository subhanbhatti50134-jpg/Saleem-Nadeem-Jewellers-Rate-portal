# License decision — Saleem-Nadeem Jewellers Rate Portal

This repository (a small gold/silver rate portal for a jewellery shop) does
**not** yet carry an open-source license. Until a license is added, all rights
are reserved by default.

## Context

This is a lightweight storefront site for a specific business. Its main value
is serving that shop's customers, not being reused by others. You have two
reasonable paths:

### Option A — Proprietary / "All Rights Reserved" (current state)
- You keep full control of the design, rates display, and shop branding.
- Others cannot legally reuse or redistribute it.
- Appropriate for a site tied to a single business.

### Option B — MIT License (permissive)
- Lets other developers reuse the rate-portal structure/components.
- Short, clear, with a warranty disclaimer.
- Good if you want the code to be a reusable template for other jewellers.

## Recommendation

For a single-business storefront, **Option A (no license)** is perfectly
reasonable. Choose MIT only if you want others to freely reuse the code.

## How to adopt (if choosing MIT)

1. Add a `LICENSE` file at the repository root with the MIT license text.
2. Add copyright: `Copyright (c) 2026 Muhammad Subhan`.
3. Keep this `LICENSE_DECISION.md` as the decision record.

> Do not treat this repository as open-source licensed until a `LICENSE` file
> is present.
